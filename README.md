# 专业智能取名大师 · Good Name Skill

> 内置中英双语言取名系统的 WorkBuddy 技能，覆盖中文个人取名、英文个人取名、商业公司品牌取名三大核心场景。

---

## 简介

**Good Name Skill** 是一个 [WorkBuddy](https://www.codebuddy.cn/docs/workbuddy/Overview) 技能包，将专业命名知识体系封装为可复用的 AI 技能。它不是简单的名字生成器，而是内置了五行调和、音韵平仄、辈分适配、文化词源、商标规避等专业命名逻辑的智能系统，每次生成至少 5 个候选名称并附带释义，支持多轮迭代优化。

### 核心亮点

- **三大场景全覆盖** — 中文个人名、英文个人名、公司品牌名，一站式解决命名需求
- **专业命名逻辑** — 五行属性匹配、声调平仄搭配、文化词源考究、商标风险规避
- **中英双语言** — 中文名讲寓意音律，英文名讲词源含义，公司名中英双名同步输出
- **多轮迭代优化** — 用户追加限制条件后，清空旧名单全新生成，绝不输出不符合新约束的旧名字
- **严格质量约束** — 生僻字/贬义字/不雅谐音/俚语负面义/商标碰瓷全方位规避

## 功能场景

### 场景一：中文个人取名

为宝宝或自己取一个寓意美好、音韵和谐的中文名。

**接收信息**：性别、辈分用字、五行喜用、期望寓意、音韵偏好、指定包含/规避汉字

**命名逻辑**：
- 字形美观 — 结构匀称，笔画适中
- 声调平仄搭配 — 避免三字同声调，追求抑扬顿挫
- 无拗口读音 — 声母不重复，韵母不相近
- 五行调和 — 按喜用选用对应五行属性汉字
- 家风辈分适配 — 辈分字自然融入
- 三重核查 — 生僻字、贬义字、不雅谐音逐项排除

### 场景二：英文个人取名

取一个贴合海外使用习惯、发音顺口、含义积极的英文名。

**接收信息**：性别、偏好文化来源、期望内涵、音节长短、指定首字母、规避字母组合

**命名逻辑**：
- 六大文化词源库 — 北欧 / 拉丁 / 希腊 / 英伦 / 凯尔特 / 希伯来
- 性别严格区分 — 男女专属名不混淆（除非用户要中性名）
- 俚语负面义规避 — 核查英语语境中的引申义
- 发音顺口 — 音节自然，重音合理
- 拼写简洁 — 避免非常规拼写

### 场景三：商业公司品牌取名

为公司或品牌取一个简短易传播、适配行业调性、商标风险低的名字。

**接收信息**：细分行业、品牌风格、命名形式倾向、指定关键字、目标客群

**命名逻辑**：
- 八大行业调性映射 — 科技/餐饮/教育/金融/美妆/零售/医疗/文创
- 五种品牌风格 — 简约现代/国风古典/潮流年轻/国际化轻奢/国风新中式
- 商标规避 — 不碰瓷知名品牌，降低商标驳回概率
- 中英双名 — 同时输出中文与英文品牌名，便于双语传播
- 五种命名形式 — 谐音取名/词汇拼接/英文缩写/中西融合/意象联想

## 安装方式

### 方式一：安装打包文件（推荐）

将 `good-name-skill.zip` 下载到本地，在 WorkBuddy 中通过技能安装入口导入即可。

### 方式二：手动放置技能目录

将 `good-name-skill/` 目录复制到 WorkBuddy 技能目录：

```bash
# 用户级技能（所有项目可用）
cp -r good-name-skill ~/.workbuddy/skills/

# 或项目级技能（仅当前项目可用）
cp -r good-name-skill .workbuddy/skills/
```

## 使用方式

安装技能后，在 WorkBuddy 对话中直接发起取名请求即可触发技能。

### 示例对话

**中文个人取名：**

> 帮我给男孩起个中文名，辈分字是「德」，五行喜水，希望寓意聪慧志远，不要太常见的名字。

**英文个人取名：**

> 我想取个英文名，女生，偏好北欧风格，含义希望和「光明」有关，2-3个音节，首字母最好是 E。

**公司品牌取名：**

> 我要开一家国风新中式茶饮品牌，面向年轻女性客群，希望名字有东方意境但不要太古典，中英文都要。

### 输出格式

技能会按照统一规范输出，以中文个人名为例：

```
## 中文个人名

1. **德泽远** — 德行润泽，志向高远（平仄仄，渐强有力）
2. **德泓睿** — 德配泓深，睿智通达（平仄仄，音韵清朗）
3. **德淳熙** — 德性淳厚，光明熙和（平平平转仄，温润收尾）
4. **德瀚哲** — 德如瀚海，哲思明达（仄仄仄转平，铿锵大气）
5. **德霖聪** — 德泽如霖，聪颖不凡（平仄平，抑扬柔和）
```

## 全局硬性约束

所有命名场景均严格遵守以下约束：

| 约束类别 | 规则 |
|---------|------|
| 中文名称 | 禁用生僻字/异体字；杜绝不雅谐音/负面字义/网络贬义词 |
| 英文名称 | 规避俚语负面含义/歧义词汇；拼写简洁不冗长 |
| 公司名称 | 规避知名品牌碰瓷；降低商标近似风险；不侵权 |
| 通用要求 | 易读、易记、口语传播性强；信息缺失时主动引导补齐 |

## 技术实现

### 渐进式加载设计

技能采用三层加载体系，高效管理上下文：

1. **元数据层**（始终加载）— 技能名称与描述，约 100 字
2. **SKILL.md 层**（触发时加载）— 主指令与工作流程，约 2000 字
3. **参考知识库层**（按需加载）— 进入对应场景时读取相应 references 文件

### 迭代优化机制

用户追加限制条件后，技能会**清空原有全部名单**，全新生成符合新条件的候选方案，不输出任何不符合新约束的旧名字。支持的追加限制包括：

- 指定包含/规避的汉字或字母
- 固定首字母
- 调整品牌风格
- 修改五行喜用
- 变更文化来源
- 调整音节长度
- ...等
