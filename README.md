# 专业智能取名大师 · Good Name Skill

> 一个面向多 agent / 多技能宿主的专业命名技能，覆盖中文个人取名、英文个人取名、公司 / 品牌命名三大场景。

---

## 简介

**Good Name Skill** 将命名知识封装为可复用的 `SKILL.md + references/` 技能包。它不是简单的名字生成器，而是通过场景化规则、按需加载的参考库和明确的风险提示，帮助支持 skills 的 agent 在多轮对话里稳定产出更像“命名方案”而不是“词语随机拼接”的候选结果。

### 核心亮点

- **三大场景全覆盖**：中文个人名、英文个人名、公司 / 品牌名
- **强调低重名与低套路化**：扩充参考库，默认规避爆款模板与伪多样化名单
- **中英双语命名能力**：中文重寓意与音律，英文重词源与可读性，品牌支持中英文双名
- **多轮约束迭代**：用户追加条件后重生完整名单，而不是修补旧名单
- **风险表达克制**：给启发式规避建议，不把商标、法律、俚语排查说成已核实事实

---

## 适用宿主

适用于**支持技能目录加载、并能识别 `SKILL.md` 的 agent / CLI / 对话宿主**，例如：

- Codex / OMX
- WorkBuddy
- 其他兼容 `skills/<skill-name>/SKILL.md` 约定的本地或项目级技能系统

如果你的宿主不使用同样的技能目录约定，也可以把本仓库内容当作命名提示工程模板或参考知识库手动迁移。

## 功能场景

### 场景一：中文个人取名

适合宝宝名、个人改名、字辈命名、按寓意 / 五行 / 音韵定制取名。

**典型输入**：
- 姓氏、性别、期望寓意
- 辈分字、单双名偏好、五行喜用
- 指定包含字 / 规避字

**处理重点**：
- 五行属性与语义平衡
- 音韵平仄与连读顺口
- 热门字降权，避免大面积重名模板
- 谐音、贬义、字形与使用成本自检

### 场景二：英文个人取名

适合海外学习 / 工作名、社交英文名、文化风格定制英文名。

**典型输入**：
- 性别偏好、期望内涵
- 使用地区 / 语境、姓氏拼音
- 首字母、音节长度、文化来源偏好

**处理重点**：
- 词源与气质匹配
- 发音顺口、拼写不过难
- 默认规避最热门撞名款
- 中性名边界与文化使用风险提示

### 场景三：公司 / 品牌命名

适合公司名、品牌名、产品线名、工作室名、店铺名。

**典型输入**：
- 细分行业、品牌风格、目标市场
- 目标客群、关键词、中英文双名需求
- 命名形式偏好、域名偏好、禁用词

**处理重点**：
- 行业调性与客群审美适配
- 显著性与传播性平衡
- 避免行业通用词堆叠
- 只做启发式商标规避，不冒充正式检索

## 项目结构

```text
GoodNameSkill/
├── README.md                          # 项目说明文档（本文件）
├── good-name-skill.zip                # 可分发的打包文件（如宿主支持导入）
└── good-name-skill/                   # 技能包根目录
    ├── SKILL.md                       # 技能主指令文件
    └── references/                    # 按场景加载的参考知识库
        ├── chinese-naming-rules.md    # 中文个人命名：低重名策略/五行/音韵/字库
        ├── english-naming-rules.md    # 英文个人命名：词源/风格/可读性/低撞名策略
        └── company-naming-rules.md    # 公司品牌命名：行业/风格/构词/显著性规避
```

### 文件说明

| 文件 | 作用 |
|---|---|
| `good-name-skill/SKILL.md` | 主流程：补问、路由、输出规范、风险表达、迭代规则 |
| `references/chinese-naming-rules.md` | 中文名参考：五行、低重名、风格矩阵、语义模板、自检 |
| `references/english-naming-rules.md` | 英文名参考：词源库、风格矩阵、发音拼写、自检 |
| `references/company-naming-rules.md` | 品牌名参考：行业调性、构词策略、显著性与规避建议 |

## 安装方式

### 方式一：导入打包文件

如果你的宿主支持技能包导入，可直接导入 `good-name-skill.zip`。

### 方式二：手动放置技能目录

`good-name-skill/` 是**技能包根目录**，应整体复制到目标宿主的 `skills` 目录下。不要只复制 `SKILL.md`，也不要把 `references/` 打散。

#### 通用放置规则

```text
<agent-skill-root>/
└── good-name-skill/
    ├── SKILL.md
    └── references/
        ├── chinese-naming-rules.md
        ├── english-naming-rules.md
        └── company-naming-rules.md
```

也就是说，不同宿主之间变化的只有 **`<agent-skill-root>`**，`good-name-skill/` 内部结构不要改。

#### 常见放置示例

```bash
# Codex / OMX：用户级
cp -r good-name-skill ~/.codex/skills/

# Codex / OMX：项目级
cp -r good-name-skill ./.codex/skills/

# WorkBuddy：用户级
cp -r good-name-skill ~/.workbuddy/skills/

# WorkBuddy：项目级
cp -r good-name-skill ./.workbuddy/skills/
```

如果你使用的是其他 agent / CLI，请查它的技能加载目录，把整个 `good-name-skill/` 文件夹复制进去即可。

#### 常见错误

- 错误：把 `SKILL.md` 直接丢进 `skills/` 根目录  
  正确：应保留 `skills/good-name-skill/SKILL.md`
- 错误：只复制 `references/` 或拆散目录结构  
  正确：必须保留 `good-name-skill/references/*`
- 错误：随意改目录层级  
  正确：优先保持 `good-name-skill/` 作为完整技能包目录

## 使用方式

安装后，在支持该技能的 agent 对话里直接描述命名需求即可触发。

### 示例提示词

**中文个人取名**

> 帮我给男孩起个中文名，姓周，辈分字是“德”，五行喜水，希望寓意聪慧志远，不要太常见的名字。

**英文个人取名**

> 我想取个英文名，女生，偏北欧风格，含义最好和“光明”有关，2-3 个音节，首字母是 E，尽量不要太热门。

**公司 / 品牌命名**

> 我要做一个新中式茶饮品牌，目标客群是 20-35 岁女性，偏东方意境但不要太古典，需要中英文双名，先给我低重名方向。

### 输出特点

技能默认会：

- 先补齐最关键的缺失信息
- 再读取对应场景 reference
- 输出至少 5 个候选
- 对每个候选给出释义、适配理由、风险提示、推荐等级
- 同时控制同轮候选的多样性，避免“只换一个字/一个词根”

## 全局约束

| 类别 | 规则 |
|---|---|
| 中文名 | 禁用明显生僻异体字、贬义字、不雅谐音；默认规避爆款重名字 |
| 英文名 | 规避明显负面俚语联想；控制拼写成本；默认规避过热排行榜名字 |
| 公司名 | 规避知名品牌碰瓷；优先提升显著性；不把启发式判断说成正式商标结论 |
| 通用 | 信息不足先补问；约束冲突先指出冲突；新约束到来后重生完整名单 |

## 实现思路

### 渐进式加载

技能采用三层加载结构：

1. **元数据层**：技能名与描述，负责触发
2. **`SKILL.md` 层**：工作流程、路由和输出格式
3. **`references/` 层**：按中文 / 英文 / 公司场景分别加载的详细知识库

### 为什么扩充 references

仅靠少量示例字库，模型很容易回到高频安全解，表现为：

- 中文名反复出现梓、轩、涵、熙、宸等热门字
- 英文名集中到 Olivia / Emma / Liam / Noah 一类热门名
- 品牌名堆叠“智 / 云 / 科技 / 优选 / 美颜”等通用词

因此本仓库把“低重名、低模板化、候选集合多样性”放进了 reference 规则本身，而不是只留给模型自由发挥。

## 开发与维护

- 技能结构：`SKILL.md + references/`
- 推荐维护方式：先改 reference，再改主流程约束，最后做结构校验
- 可用校验器：`skill-creator` 附带的 `quick_validate.py`

示例：

```bash
python "${CODEX_HOME:-$HOME/.codex}/skills/.system/skill-creator/scripts/quick_validate.py" good-name-skill
```

## 限制说明

- 不替代正式商标检索、法律检索或姓名学认证
- 不保证“绝对不重名”，只能通过规则与素材库尽量降低撞名概率
- 不保证跨所有地区、方言、俚语环境都无歧义，只能给启发式风险提示
