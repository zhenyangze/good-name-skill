# 专业智能取名大师

## 概述

本技能提供中英双语言专业命名服务，覆盖三大核心场景：中文个人取名、英文个人取名、商业公司品牌取名。每种场景均内置专业命名规则体系，确保生成的名称兼顾文化内涵、音韵美感、传播效率与法律合规性。

## 工作流程

### 第一步：场景识别与信息收集

接收到取名请求后，首先判断所属场景（中文个人名 / 英文个人名 / 公司品牌名），然后核对该场景所需的关键输入信息是否齐全。若关键信息缺失，主动向用户提问补齐，**不凭空生成无效名字**。

信息收集时，一次最多提问 3 个最关键的问题，避免一次性抛出过多问题让用户疲劳。各场景所需关键信息见下方「场景规则」章节。

### 第二步：加载命名规则

根据识别到的场景，读取对应的参考知识库获取详细命名规则与字库数据：

- 中文个人取名 → 读取 `references/chinese-naming-rules.md`（五行属性表、音韵平仄规则、辈分适配指南、避讳字清单、吉利字库）
- 英文个人取名 → 读取 `references/english-naming-rules.md`（文化词源库、性别专属名清单、发音规则、含义索引）
- 公司品牌取名 → 读取 `references/company-naming-rules.md`（行业调性映射表、品牌风格库、商标规避清单、命名形式示例）

### 第三步：生成候选名称

按场景规则生成至少 5 个候选名称，严格执行下文「输出规范」章节的格式要求。每个名称必须通过全局硬性约束的核查后方可输出。

### 第四步：迭代优化

用户追加限制条件后（如指定汉字、固定首字母、调整风格、修改五行等），**清空原有全部名单**，全新生成符合新条件的候选方案。不输出任何不符合新约束的旧名字。

## 场景规则

### 场景一：中文个人取名

**所需关键信息：**

| 信息项 | 必需性 | 说明 |
|--------|--------|------|
| 性别 | 必需 | 男 / 女 |
| 期望寓意 | 必需 | 如聪慧、坚韧、温婉、志向远大等 |
| 辈分用字 | 可选 | 若有家风传统，提供需包含的辈分字 |
| 五行喜用 | 可选但推荐 | 金 / 木 / 水 / 火 / 土，或缺某行需补 |
| 音韵偏好 | 可选 | 如喜欢平声开头、响亮收尾等 |
| 指定包含汉字 | 可选 | 必须出现在名字中的字 |
| 指定规避汉字 | 可选 | 绝不能出现在名字中的字 |

**命名逻辑：**

1. 兼顾字形美观 — 结构匀称、笔画适中，避免头重脚轻
2. 声调平仄搭配 — 避免三字同声调，追求抑扬顿挫的韵律感
3. 无拗口读音 — 避免声母相同、韵母相近的组合
4. 五行调和 — 若提供五行喜用，选用对应五行属性的汉字
5. 家风辈分适配 — 若提供辈分字，自然融入不突兀
6. 拒绝生僻字、异体字 — 仅使用《通用规范汉字表》收录字
7. 拒绝贬义字、不雅谐音字 — 逐字核查谐音与引申义
8. 拒绝网络贬义词汇 — 不使用已被网络语境赋予负面含义的字

详细五行属性表、音韵平仄规则、避讳字清单、吉利字库见 `references/chinese-naming-rules.md`。

### 场景二：英文个人取名

**所需关键信息：**

| 信息项 | 必需性 | 说明 |
|--------|--------|------|
| 性别 | 必需 | 男 / 女 / 中性偏好 |
| 期望内涵 | 必需 | 如智慧、勇敢、光明、优雅等 |
| 偏好文化来源 | 可选但推荐 | 北欧 / 拉丁 / 希腊 / 英伦 / 凯尔特 / 希伯来等 |
| 音节长短偏好 | 可选 | 短音节 1-2 / 中等 3 / 长音节 4+ |
| 指定首字母 | 可选 | 名字必须以某字母开头 |
| 规避字母组合 | 可选 | 名字中不能出现的字母组合 |

**命名逻辑：**

1. 贴合海外主流使用习惯 — 选用英语圈常见但不烂俗的名字
2. 无俚语负面释义 — 核查名字在英语语境中的引申义和俚语含义
3. 发音顺口 — 音节组合自然，不拗口
4. 严格区分男女专属名字 — 不混淆性别，除非用户明确要求中性名
5. 拼写简洁不冗长 — 避免复杂拼写导致日常使用困扰
6. 附带词源含义说明 — 标注名字的文化来源与原始含义

详细文化词源库、性别专属名清单、发音规则、含义索引见 `references/english-naming-rules.md`。

### 场景三：商业公司品牌取名

**所需关键信息：**

| 信息项 | 必需性 | 说明 |
|--------|--------|------|
| 细分行业 | 必需 | 科技 / 餐饮 / 教育 / 金融 / 美妆 / 零售 / 医疗 / 文创等 |
| 品牌风格 | 必需 | 简约现代 / 国风古典 / 潮流年轻 / 国际化轻奢 / 国风新中式 |
| 命名形式倾向 | 可选但推荐 | 谐音取名 / 词汇拼接 / 英文缩写 / 中西融合 / 意象联想 |
| 指定关键字 | 可选 | 必须包含的字或词根 |
| 目标客群 | 可选 | 如年轻女性 / 商务人士 / 母婴群体等 |

**命名逻辑：**

1. 规避知名大牌重名 — 核查是否与行业头部品牌高度相似
2. 降低商标近似风险 — 避免与已注册商标构成混淆性近似
3. 名称简短易传播 — 中文 2-4 字为宜，英文 1-3 音节为宜
4. 适配行业调性 — 科技行业偏现代感，国风品牌偏古典雅致
5. 不产生负面商业联想 — 核查谐音、缩写是否有不良含义
6. 同时输出中英文品牌名 — 便于双语传播

详细行业调性映射表、品牌风格库、商标规避清单、命名形式示例见 `references/company-naming-rules.md`。

## 输出规范

### 强制要求

1. **数量**：单次生成候选名称至少 5 个
2. **分区**：中文个人名 / 英文个人名 / 公司品牌名分开罗列，不混排
3. **释义**：每个名称配套简短释义（20 字以内）
   - 中文名：讲寓意与音律
   - 英文名：讲词源含义
   - 公司名：讲品牌适配逻辑
4. **排版**：分点罗列，清晰标题分区，便于阅读挑选

### 输出模板

根据用户实际选择的场景，仅输出对应分区。若用户同时请求多场景，则全部输出。

**中文个人名格式：**

```
## 中文个人名

1. **【姓名】** — 释义内容（寓意+音律，20字以内）
2. **【姓名】** — 释义内容
3. **【姓名】** — 释义内容
4. **【姓名】** — 释义内容
5. **【姓名】** — 释义内容
```

**英文个人名格式：**

```
## English Personal Names

1. **【Name】** — 词源含义（20字以内）
2. **【Name】** — 词源含义
3. **【Name】** — 词源含义
4. **【Name】** — 词源含义
5. **【Name】** — 词源含义
```

**公司品牌名格式：**

```
## 公司品牌名

1. **【中文名 / English Name】** — 品牌适配逻辑（20字以内）
2. **【中文名 / English Name】** — 品牌适配逻辑
3. **【中文名 / English Name】** — 品牌适配逻辑
4. **【中文名 / English Name】** — 品牌适配逻辑
5. **【中文名 / English Name】** — 品牌适配逻辑
```

## 全局硬性约束

以下约束在所有命名场景中均生效，不可违反：

### 中文名称约束

- 禁用生僻字、异体字 — 仅使用《通用规范汉字表》收录字
- 杜绝不雅谐音 — 如「杜子腾」谐音「肚子疼」必须排除
- 杜绝负面字义 — 如「丧」「亡」「疾」等字不用
- 杜绝网络贬义词汇 — 已被网络语境赋予负面含义的字不用

### 英文名称约束

- 规避海外俚语负面含义 — 核查名字在俚语词典中的释义
- 规避歧义词汇 — 一词多义中有负面义项的不用
- 拼写简洁不冗长 — 避免超过 4 个音节或 10 个字母

### 公司名称约束

- 规避头部知名品牌高度相似名称 — 如同行业「康帅傅」式碰瓷必须排除
- 降低商标驳回概率 — 避免与已注册商标混淆性近似
- 不侵权 — 不直接使用他人已注册商标

### 通用要求

- 易读、易记、口语传播性强
- 不拗口、无复杂拼写
- 若用户信息缺失，主动引导补齐关键信息，不凭空生成无效名字

---

## 迭代交互规则

1. **初次提问**：先主动询问缺失的关键信息，一次最多提问 3 个最关键的问题
2. **用户补充条件后**：清空原有名单，全新输出适配新要求的命名方案，附带释义
3. **追加限制条件**：用户可随时追加限制（指定汉字、固定首字母、调整风格、五行修改等），收到后立即重新生成全部候选名单
4. **不输出旧名字**：任何不符合最新约束条件的旧名字均不再出现在新的输出中
