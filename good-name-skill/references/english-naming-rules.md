# 英文个人取名规则参考库

本文件为英文个人取名场景的专业规则参考，重点补强“不要整批落入最热门榜单模板”“不要所有名字都像同一所学校的一届新生”这两个问题。

---

## 一、低重名优先策略

### 1. 默认降权的超高频英文名

以下名字并非禁用，但若用户没有明确要求“经典主流、最常见、最安全”，默认降权：

- 男名高频：Liam, Noah, Oliver, James, Elijah, William, Henry, Lucas, Benjamin, Alexander
- 女名高频：Olivia, Emma, Charlotte, Amelia, Sophia, Isabella, Ava, Mia, Evelyn, Harper
- 中性高频：Avery, Riley, Quinn, Harper, Taylor, Jordan, Cameron

### 2. 常见爆款替代方向

| 高热名字 | 替代方向 | 更不易撞名的可读选项 |
|---|---|---|
| Olivia | 同样柔美经典 | Elodie, Lydia, Celia, Linnea |
| Emma | 同样简洁亲和 | Etta, Alma, Thea, Esme |
| Sophia | 同样智慧优雅 | Sonia, Seraphine, Thalia, Minerva |
| Liam | 同样简洁有力 | Leon, Ellis, Jonas, Emmett |
| Noah | 同样温和国际化 | Nolan, Jonah, Ronan, Asa |
| Oliver | 同样经典文雅 | Orson, Oscar, Alistair, Evander |

### 3. 候选集合去同质化规则

同一轮候选至少拉开 3 个维度：

1. 词源不同：如 Latin / Greek / Celtic 混合
2. 音节不同：1-2 音节与 3 音节混合
3. 气质不同：classic / modern / literary / airy / crisp
4. 拼写骨架不同：不要全是元音结尾或全是 -ia / -an / -er

## 三、风格矩阵

### 1. Classic Safe

- 气质：传统、稳妥、跨地区通行
- 男名：Arthur, Julian, Theodore, Edward, Daniel
- 女名：Clara, Alice, Eleanor, Lucia, Hannah

### 2. Literary / Bookish

- 气质：书卷、文艺、略带古典
- 男名：Cassian, Lysander, Edmund, Alaric, Phineas
- 女名：Beatrice, Cressida, Imogen, Elowen, Octavia

### 3. Modern Clean

- 气质：简洁、当代、不过度流行
- 男名：Leon, Ellis, Ronan, Stellan, Emmett
- 女名：Thea, Alma, Elara, Eira, Celia

### 4. Airy / Gentle

- 气质：轻盈、柔和、干净
- 男名：Asa, Jonah, Callum, Elior, Lucian
- 女名：Linnea, Talia, Serena, Alva, Niamh

### 5. Strong / Regal

- 气质：力量、贵气、领导感
- 男名：Magnus, Evander, Victor, Leander, Rupert
- 女名：Astrid, Sigrid, Matilda, Victoria, Orla

## 五、发音与拼写规则

### 音节搭配原则

1. 1-2 音节：简洁有力，如 Leon, Eira, Thea, Ronan
2. 3 音节：韵律更完整，如 Eleanor, Julian, Eliana
3. 4+ 音节：更华丽，但需确认用户能接受，如 Aurelia, Sebastian

### 发音顺口标准

1. 避免极少见辅音簇
2. 保持重音位置自然，优先第一或第二音节
3. 若缺姓氏，不要强说 full-name flow 已校验
4. 如面向非英语母语环境，优先选“看到就大致会读”的名字

### 拼写简洁标准

1. 4-8 字母优先
2. 避免非常规拼写，如 Khayleigh, Jaxsyn
3. 避免“读音好但拼写成本太高”的名字，除非用户明确偏好稀有正统拼写

## 七、取名自检清单

生成英文名后，逐项核查：

- [ ] 性别匹配：严格男/女名不混用，中性名需用户确认
- [ ] 文化来源：符合用户偏好词源（若有指定）
- [ ] 含义积极：词源含义正向，无明显负面引申
- [ ] 无俚语负面义：至少做常见语境层面的启发式规避
- [ ] 发音顺口：音节自然，重音合理
- [ ] 拼写简洁：字母数适中，拼写不怪异
- [ ] 首字母符合：若用户指定首字母则匹配
- [ ] 无规避字母组合：若用户指定规避则已排除
- [ ] 音节长度：符合用户偏好（若有指定）
- [ ] 低重名：默认不整组落在近年最热门榜单的前列模板
- [ ] 集合多样性：同轮候选的词源、韵律、结尾形式有区分
