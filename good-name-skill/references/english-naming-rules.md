## 三、发音规则

### 音节搭配原则

1. **短音节名（1-2音节）** — 简洁有力，易记易叫：Max, Leo, Ava, Zoe, Jack, Finn
2. **中等音节名（3音节）** — 韵律优美，经典耐听：Olivia, Benjamin, Victoria, Alexander
3. **长音节名（4+音节）** — 优雅华丽，但日常使用略长：Alexander, Anastasia, Evangeline

### 发音顺口标准

1. **避免连续相同辅音** — 如「Bartholomew」中 th-l-m 连续不同辅音簇，对非母语者略难
2. **元音变化丰富** — 音节中元音有变化的更顺口，如「Olivia」（o-i-i-a）比连续相同元音更悦耳
3. **重音自然** — 英文名重音通常在第一或第二音节，避免重音在生僻位置
4. **与姓氏搭配** — 名字与姓氏连读时音节不冲突，如「James Smith」比「Alexander Alexander」自然

### 拼写简洁标准

1. **字母数建议** — 4-8 个字母为佳，超过 10 个字母的日常使用不便
2. **避免非常规拼写** — 如「Khayleigh」替代「Kayleigh」会增加拼写困扰
3. **发音与拼写一致** — 避免如「Siobhan」（读 shi-VAHN）这类非英语母语者难以拼读的名字

## 五、取名自检清单

生成英文名后，逐项核查：

- [ ] 性别匹配 — 严格男/女名不混用，中性名需用户确认
- [ ] 文化来源 — 符合用户偏好词源（若有指定）
- [ ] 含义积极 — 词源含义正向，无负面引申
- [ ] 无俚语负面义 — 核查英语俚语中是否有不良含义
- [ ] 发音顺口 — 音节自然，重音合理
- [ ] 拼写简洁 — 字母数适中，拼写常规
- [ ] 首字母符合 — 若用户指定首字母则匹配
- [ ] 无规避字母组合 — 若用户指定规避则已排除
- [ ] 音节长度 — 符合用户偏好（若有指定）
