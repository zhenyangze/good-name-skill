# 公司品牌取名规则参考库

本文件为商业公司品牌取名场景的专业规则参考，重点补强“不要只会拼行业通用词”“不要一眼像别家二创”的区分度能力。

---

## 一、先做区分度分层

默认优先级：

1. **独创型**：新词、变体词、双语映射词
2. **意象型**：借自然/秩序/空间/时间等意象表达品牌气质
3. **中西融合型**：中文意境 + 英文构词
4. **轻描述型**：能暗示行业，但不直接把行业词堆满
5. **强描述型**：只在用户明确要求“看懂业务优先”时才上升

### 默认降权的泛化套路

- 科技：智、云、数、链、未来、AI、科技、智能、云端
- 餐饮：鲜、味、香、食、厨、小馆、铺子、食堂
- 教育：学、教育、成长、课堂、启航、培优
- 金融：财富、资本、金服、投资、基金、资管
- 美妆：美、颜、肌、妆、花、自然、精华

这些词不是禁用，但若直接堆叠，极易出现“行业里到处都像”的重名感与低显著性。

## 二、行业调性映射表

不同行业有固有气质，命名时先选“调性轴”，再选“构词轴”。

### 科技行业

- 调性关键词：创新、未来、精度、效率、系统、连接
- 中文种子：维、序、矩、界、跃、源、枢、算、极、宙
- 英文词根：nova, nexus, vector, pulse, lumen, orbit, grid, forge
- 低同质化提示：少直接用“智云数链”，可转向“秩序 / 枢纽 / 路径 / 精度”语义

### 餐饮行业

- 调性关键词：美味、烟火、手作、温度、地域感、记忆点
- 中文种子：灶、炉、盏、巷、炊、席、宴、谷、禾、汤
- 英文词根：feast, hearth, savor, grain, ladle, ember, simmer
- 低同质化提示：少堆“鲜香味”，可转向“火候 / 器皿 / 时令 / 场景”

### 教育行业

- 调性关键词：启发、成长、方法、陪伴、认知、未来
- 中文种子：启、识、知、见、程、阶、问、曜、桥、拓
- 英文词根：mind, spark, atlas, bridge, quest, lumen, stride
- 低同质化提示：少直接用“学而思式”结构，可转向“路径 / 认知 / 陪跑”

### 金融行业

- 调性关键词：稳健、秩序、专业、复利、信任、边界
- 中文种子：衡、信、诚、鼎、序、远、固、盛、澄、宁
- 英文词根：prime, sterling, meridian, vault, harbor, axis, summit
- 低同质化提示：少直接用“财富资本”，可转向“秩序 / 航向 / 守护 / 坐标”

### 美妆行业

- 调性关键词：质感、光泽、肌理、自然、高级、悦己
- 中文种子：釉、绽、绒、澄、岚、漾、曜、颜、露、绮
- 英文词根：aura, bloom, veil, velvet, gleam, flora, dew, lune
- 低同质化提示：少直接用“花颜美肌”，可转向“材质 / 光感 / 植物 / 氛围”

### 零售行业

- 调性关键词：精选、日常、效率、可信、陪伴、生活感
- 中文种子：集、选、里、邻、仓、篱、度、拾、简、好
- 英文词根：daily, gather, nook, home, select, pantry, parcel
- 低同质化提示：少堆“优选严选精选”，可转向“生活场景 / 社区 / 组织方式”

### 医疗行业

- 调性关键词：专业、关怀、恢复、生命、安心、精确
- 中文种子：康、愈、仁、安、和、瑞、衡、护、澄、益
- 英文词根：care, vital, cure, pulse, well, mercy, restore, med
- 低同质化提示：少直用“健康医疗”，可转向“修复 / 守护 / 生命节律”

### 文创行业

- 调性关键词：审美、故事、灵感、器物、表达、意境
- 中文种子：墨、弦、境、序、匠、物、叙、观、野、织
- 英文词根：craft, muse, fable, loom, studio, tale, echo, forge
- 低同质化提示：少直接用“文创艺术设计”，可转向“叙事 / 材质 / 空间 / 时间”

## 三、品牌风格库

### 简约现代

- 特征：短、直、利落、可视化强
- 中文路径：单字强语义 / 双字秩序感 / 几何词
- 英文路径：单词或双音节造词
- 示例方向：序界、维度、跃点 / Vector, Nexo, Luma

### 国风古典

- 特征：典雅、含蓄、余韵
- 中文路径：诗词意象 / 器物节气 / 山水草木
- 英文路径：意译或辅助名，不必强直译
- 示例方向：半盏、观岚、栖川 / Verna, Cedar, Morrow

### 潮流年轻

- 特征：轻松、记忆点强、口语传播性好
- 中文路径：反差、轻谐音、中英混搭、场景化
- 英文路径：短促、节拍感强
- 示例方向：不设限、开饭啦、野一下 / Poply, Movo, Vibee

### 国际化轻奢

- 特征：高级、跨文化、质感、留白
- 中文路径：少字、材质感、光感、空间感
- 英文路径：拉丁/法式气质词根、柔和音节造词
- 示例方向：曜岚、澄绒、序光 / Aureve, Velune, Meris

### 国风新中式

- 特征：东方意境 + 当代传播
- 中文路径：古字新用 / 器物 + 情绪 / 中西映射
- 英文路径：不必直译，可做东方气质的再创造
- 示例方向：闻弦、见山、照隐 / Yura, Zorin, Qiora

## 四、命名构词策略库

### 1. 语义轴组合

优先跨语义轴组合，而不是同轴硬拼。

- 秩序 + 速度：序跃、衡行、Vectora
- 光感 + 材质：曜绒、澄釉、Velune
- 场景 + 情绪：半盏、邻里、Harborly
- 自然 + 系统：岚序、川界、Orbitree

### 2. 中文构词模板

1. **器物 / 空间 + 气质**：半盏、序馆、桥野
2. **自然意象 + 动作**：观夏、拾光、听岚
3. **秩序 / 坐标 + 愿景**：维程、衡远、序见
4. **材质 / 光影 + 感受**：曜绒、澄釉、雾岚

### 3. 英文构词模板

1. **真实词根 + 柔化后缀**：Luma + -ra → Lumara
2. **两段意象拼接**：Harbor + Bloom → Harborbloom
3. **功能隐喻 + 轻抽象**：Axis + -en → Axisen
4. **自然词 + 科技词**：Orbit + Grove → Orbitgrove

### 4. 后缀 / 结尾灵感

- 中文尾感：序、里、间、野、光、岚、川、弦、域、集
- 英文尾感：-ra, -lo, -is, -en, -ora, -ive, -ium, -ly, -on

注意：造词必须解释来源；不能给纯随机字母组合。

## 五、商标与显著性启发式规避

### 绝对规避类

1. 知名品牌直接重名
2. 知名品牌高度近似
3. 驰名商标跨类碰瓷
4. 直接把头部品牌改一字当新名

### 高风险信号

1. 只由行业通用词组成：如“智慧科技”“优选生活”
2. 只描述功能，没有品牌性：如“在线英语课堂”
3. 与头部品牌仅一字之差或谐音接近
4. 中文和英文都太普通，无法形成识别点

### 降低风险的命名策略

1. 用独创词或二次语义映射提升显著性
2. 在通用词之外增加区分元素
3. 若做中英文双名，保持“意象一致、字面不必硬直译”
4. 若用户未提供地区与类别，不要声称风险低，只能给启发式规避建议

## 六、命名形式示例

### 谐音取名

适合年轻化或餐饮消费类，但必须确保谐音正向、不过火。

- 柿柿如意
- 莓烦恼
- 谷得好

### 词汇拼接

适合建立新词感。

- 茶颜悦色
- 花西子
- 序光

### 英文缩写

适合 B2B、科技、专业服务，但需解释缩写来源。

- IBM
- BMW
- APM（示例：Axis Pulse Metrics）

### 中西融合

适合兼顾中文传播与海外表达。

- 花西子 / Florasis
- 字节跳动 / ByteDance
- 见山 / Orivue（示例：origin + view）

### 意象联想

适合文创、美妆、茶饮、生活方式品牌。

- 观夏
- 煮雪
- 闻弦
- 桥野

## 七、候选集合多样性规则

同一轮品牌候选，至少覆盖以下 3 类中的 3 类：

1. 独创词
2. 意象词
3. 轻描述词
4. 中西融合词
5. 缩写 / 首字母词

不要交付这种伪多样化名单：

- 智云科技 / 智云未来 / 云智科技 / 智能云科 / 云智未来
- 花颜 / 花妍 / 花研 / 花言 / 花漾

## 八、取名自检清单

生成公司品牌名后，逐项核查：

- [ ] 行业适配：名称气质符合所属行业调性
- [ ] 风格匹配：符合用户指定品牌风格
- [ ] 简短易传播：中文优先 2-4 字，英文优先 1-3 音节或可拆读造词
- [ ] 无知名品牌碰瓷：不与头部品牌高度相似
- [ ] 显著性足够：不只是行业通用词堆叠
- [ ] 无负面联想：谐音、缩写、语义无明显不良含义
- [ ] 中英双名协调：若需要双名，语义方向一致
- [ ] 形式符合偏好：若用户指定命名形式则匹配
- [ ] 关键字处理得当：若用户指定关键词，避免生硬塞词
- [ ] 目标客群适配：审美与受众心智一致
- [ ] 集合多样性：同轮候选不是单一模板批量改字
