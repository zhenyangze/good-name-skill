本文件为商业公司品牌取名场景的专业规则参考，包含行业调性映射、品牌风格库、商标规避清单、命名形式示例等核心知识。

## 二、品牌风格库

### 简约现代

**风格特征**：字数少、含义直接、无过多修饰、视觉清爽

**命名手法**：
- 单字或双字直接表意
- 英文单词直接使用
- 几何感强的字词组合

**示例参考**：
- 科技类：极智、跃迁 / Nova, Apex
- 零售类：优选、好物 / Pure, Daily
- 餐饮类：鲜灶、味觉 / Bite, Fresh

### 国风古典

**风格特征**：典雅、含蓄、意境深远、用词典雅

**命名手法**：
- 引经据典（诗词、典故）
- 古雅字词
- 意象联想（山水、四时、节气）

**示例参考**：
- 茶饮类：煮雪、听泉、半盏
- 文创类：墨韵、观山、拾光
- 美妆类：兰心、花颜、玉容

### 潮流年轻

**风格特征**：活泼、个性、网感、反差感

**命名手法**：
- 谐音梗（正向、有趣）
- 中英混搭
- 反常规组合
- 叠字或语气词

**示例参考**：
- 零售类：好物研究所、不踩雷
- 餐饮类：肉食者联盟、碳水快乐
- 美妆类：颜究所、不脱妆

### 国际化轻奢

**风格特征**：高级感、简洁、跨文化、品质暗示

**命名手法**：
- 法语/意大利语词根
- 抽象音节组合
- 首字母缩写
- 极简英文单词

**示例参考**：
- 美妆类：Lumiere, Aura, Belle
- 服饰类：Maison, Atelier, L'aura
- 金融类：Sterling, Meridian, Prime

### 国风新中式

**风格特征**：传统与现代结合、东方美学、年轻化表达

**命名手法**：
- 古字新用
- 中西融合（中文意境+英文音译）
- 新中式意象
- 传统元素年轻化

**示例参考**：
- 茶饮类：茶颜悦色、霸王茶姬
- 美妆类：花西子、毛戈平
- 文创类：观夏、闻弦

## 三、商标规避清单

### 绝对规避类

1. **知名品牌直接重名** — 不可使用与知名品牌完全相同的名称
2. **知名品牌高度相似** — 不可使用仅一字之差的碰瓷名：
   - 康帅傅（康师傅）❌
   - 营养抉线（营养快线）❌
   - 王老世家（王老吉）❌
   - 三个松鼠（三只松鼠）❌
3. **驰名商标跨类保护** — 驰名商标享有跨类保护，即便不同行业也不可使用相似名称
4. **他人已注册商标** — 不可直接使用他人已注册的商标名称

### 商标近似风险评估

1. **字形近似** — 文字字形高度相似（如「兔」与「免」）
2. **读音近似** — 读音相同或相近（如「佳」与「嘉」在同类别可能构成近似）
3. **含义近似** — 含义相同或相近（如「Sun」与「太阳」在同类别可能构成近似）
4. **组合近似** — 整体外观、读音、含义综合判断

### 降低商标风险的命名策略

1. **使用独创词汇** — 非词典中既有词汇的独创组合，显著性最强
2. **避免行业通用词** — 不可将行业通用词作为品牌名注册
3. **避免描述性词汇** — 直接描述产品特征的词汇显著性弱
4. **中英文组合** — 中文+英文组合可降低与单一语言商标的冲突概率
5. **增加区分元素** — 在常见词基础上增加独特元素

## 四、命名形式示例

### 谐音取名

利用谐音创造美好联想，需确保谐音正向。

**正向示例**：
- 「果然好」— 果然好（品质肯定）
- 「柿柿如意」— 事事如意（吉祥寓意）
- 「莓烦恼」— 没烦恼（轻松愉悦）

### 词汇拼接

将两个有意义的词拼接，创造新含义。

**示例**：
- 「茶颜悦色」— 茶+颜+悦色
- 「三只松鼠」— 数量+动物
- 「花西子」— 花+西子（美人意象）

### 英文缩写

取首字母或关键词缩写，简洁易记。

**示例**：
- 「IKEA」— Ingvar Kamprad Elmtaryd Agunnaryd
- 「IBM」— International Business Machines
- 「BMW」— Bayerische Motoren Werke

### 中西融合

中文意境与英文发音/含义结合。

**示例**：
- 「花西子 / Florasis」— 花+西子 / Flora（花）+ sis（姐妹）
- 「完美日记 / Perfect Diary」— 直译融合
- 「字节跳动 / ByteDance」— 字节+跳动 / Byte+Dance

### 意象联想

通过意象引发美好联想，不直接说产品。

**示例**：
- 「观夏」— 观+夏（夏日意境，香水品牌）
- 「煮雪」— 煮+雪（冬日温暖，茶饮意境）
- 「闻弦」— 闻+弦（琴音雅致，文创意境）

## 五、取名自检清单

生成公司品牌名后，逐项核查：

- [ ] 行业适配 — 名称气质符合所属行业调性
- [ ] 风格匹配 — 符合用户指定的品牌风格
- [ ] 简短易传播 — 中文 2-4 字，英文 1-3 音节
- [ ] 无知名品牌碰瓷 — 不与头部品牌高度相似
- [ ] 商标风险低 — 非通用词、非描述性词、有显著性
- [ ] 无负面联想 — 谐音、缩写无不良含义
- [ ] 中英双名 — 同时提供中文与英文品牌名
- [ ] 形式符合偏好 — 若用户指定命名形式则匹配
- [ ] 关键字包含 — 若用户指定关键字则已包含
- [ ] 目标客群适配 — 名称气质符合目标客群审美
