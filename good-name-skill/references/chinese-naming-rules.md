# 中文个人取名规则参考库

本文件为中文个人取名场景的专业规则参考，包含五行属性、音韵平仄、辈分适配、避讳字、吉利字库等核心知识。

## 一、五行属性表

五行喜用是中文取名的重要依据。根据用户提供的五行喜用（金/木/水/火/土），优先选用对应五行属性的汉字。

### 金属性字

偏旁部首含金、钅、刂、刀、辛、酉等，或字义与金属、锋利、坚硬相关。

常用吉利字：铭、钰、锐、鑫、锋、锦、铮、铠、钟、钦、铃、铄、鉴、铸、钊、铎、铖、锴、锶、锬

### 木属性字

偏旁部首含木、艹、竹、禾、禾等，或字义与植物、生长、生机相关。

常用吉利字：梓、桐、栩、楠、楷、森、林、彬、栋、柏、枫、荣、茂、芸、芷、萱、蕊、菲、芷、蔓

### 水属性字

偏旁部首含氵、冫、雨、鱼等，或字义与水、流动、滋润相关。

常用吉利字：泽、浩、涵、润、淼、渊、澈、澜、溪、霖、霏、露、霜、凝、淼、淳、沛、沁、泳、漪

### 火属性字

偏旁部首含火、灬、日、光等，或字义与光明、温暖、热烈相关。

常用吉利字：煜、炜、烨、焱、炎、灿、耀、晖、旭、晨、曦、晴、暖、熠、煦、炯、烁、烽、焕、明

### 土属性字

偏旁部首含土、山、石、玉等，或字义与大地、稳重、厚重相关。

常用吉利字：坤、城、培、垣、垒、墉、硕、砺、磬、瑛、瑞、瑾、瑜、璐、瑶、璞、珂、琅、瓒、璟

## 二、音韵平仄规则

### 声调基础

现代汉语四声：
- 第一声（阴平）：如「天」「花」「春」— 平声
- 第二声（阳平）：如「明」「华」「阳」— 平声
- 第三声（上声）：如「美」「海」「雨」— 仄声
- 第四声（去声）：如「丽」「健」「志」— 仄声

### 平仄搭配原则

1. **避免三字同声调** — 如「方邦刚」（全一声）过于平淡，「赵浩皓」（全四声）过于刚硬
2. **追求抑扬顿挫** — 推荐平仄交替或平仄平、仄平仄的组合
3. **收尾声调考量**：
   - 平声收尾（一、二声）：柔和悠扬，适合温婉气质
   - 仄声收尾（三、四声）：响亮有力，适合阳刚气质

### 推荐声调组合（三字名）

| 组合 | 气质 | 示例 |
|------|------|------|
| 平平仄 | 温和有力 | 林书豪 |
| 平仄平 | 抑扬柔和 | 苏雨晴 |
| 仄平平 | 先抑后扬 | 李明轩 |
| 仄平仄 | 铿锵分明 | 赵文博 |
| 平仄仄 | 渐进有力 | 陈志远 |

### 拗口读音规避

1. **避免声母相同** — 如「李丽琳」（全 l 声母）绕口
2. **避免韵母相近** — 如「金瑾琴」（in/in/in）单调
3. **避免鼻音堆积** — 如「陈晨辰」鼻音过重
4. **开口音与闭口音搭配** — 增加发音层次感

## 三、辈分适配指南

### 辈分字处理原则

1. **辈分字位置**：可在中间（如「张志远」中「志」为辈分字）或末尾（因家族规矩而异）
2. **自然融入**：辈分字需与搭配字意境协调，不可生硬拼凑
3. **字义延伸**：若辈分字字义一般，搭配字需提升整体意境
4. **音韵协调**：辈分字声调决定搭配字的声调选择

### 辈分字适配示例

假设辈分字为「德」：
- 德馨 — 德行芬芳（平仄搭配，意境高雅）
- 德泽 — 德行润泽（平仄搭配，寓意深厚）
- 德昭 — 德行昭彰（仄平搭配，响亮大气）

## 四、避讳字清单

### 绝对禁用类

1. **生僻字** — 非《通用规范汉字表》收录字，如「頔」「翀」「垚」（虽有人用但不在常用表内，影响日常使用）
2. **异体字** — 如「峯」（峰的异体）、「昇」（升的异体）
3. **贬义字** — 丧、亡、疾、苦、悲、哀、孤、寡、残、劣
4. **不雅谐音** — 逐名核查全名连读谐音：
   - 杜子腾 → 肚子疼
   - 史珍香 → 屎真香
   - 焦厚根 → 脚后跟
   - 魏生津 → 卫生巾
   - 沈京兵 → 神经病

### 网络贬义规避

避免已被网络语境赋予负面含义的字或组合，如：
- 单字「卷」「割」「韭菜」等在特定语境下有负面义
- 组合可能产生网络梗联想的需逐一核查

### 谐音核查方法

1. **正向谐音** — 全名连读是否谐音不良词汇
2. **反向谐音** — 姓名倒读是否谐音不良词汇
3. **方言谐音** — 考虑主要方言（粤语、闽南语等）中的谐音
4. **缩写谐音** — 名字首字母缩写是否构成不良含义

## 六、取名自检清单

生成中文名后，逐项核查：

- [ ] 字形美观 — 结构匀称，笔画适中（单字笔画建议 5-20 画）
- [ ] 声调搭配 — 无三字同声调，平仄有致
- [ ] 无拗口读音 — 声母不重复，韵母不相近
- [ ] 五行符合 — 若有五行要求，字属性匹配
- [ ] 辈分融入 — 若有辈分字，自然协调
- [ ] 无生僻异体字 — 均为《通用规范汉字表》收录
- [ ] 无贬义不雅谐音 — 正向、反向、方言、缩写谐音均核查
- [ ] 寓意积极 — 整体意境正向美好
