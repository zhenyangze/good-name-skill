# 中文个人取名规则参考库

本文件为中文个人取名场景的专业规则参考，重点补强“低重名、低套路化、可解释”三项能力。命名时优先用它来拉开候选之间的差异，而不是反复堆叠少数热门字。

---

## 一、低重名优先策略

### 1. 默认降权的高重名字

以下字并非禁用，但若用户没有明确要求“热门、经典、主流”，应默认降权，避免整组候选撞向同一代人的爆款模板。

- 男名常见高频字：轩、浩、宇、泽、宸、睿、博、辰、铭、毅、俊、航、哲、豪
- 女名常见高频字：涵、萱、怡、欣、悦、妍、馨、诺、汐、瑶、彤、琪、萌、依
- 中性/泛用高频字：梓、熙、然、宁、安、语、可、一、子、晨、清、嘉、锦

### 2. 热门字替代思路

优先选“常用但不过热、好写好读、语义清晰”的替代字。

| 高重名字 | 可替代方向 | 示例替代字 |
|---|---|---|
| 梓 | 木意象但降热度 | 栩、柯、楷、榆、棠、槿 |
| 轩 | 气宇轩昂但降热度 | 昂、岳、峻、昀、衡、骁 |
| 涵 | 包容温润但降热度 | 澄、沐、洵、渝、沁、潞 |
| 熙 | 光明和乐但降热度 | 晟、煦、曜、昭、晗、昕 |
| 悦 | 喜悦柔和但降热度 | 愉、恬、歆、和、宁、忻 |
| 宸 | 尊贵大气但降热度 | 衡、景、维、峥、奕、祺 |
| 汐 | 灵动水感但降热度 | 漪、泠、沄、澜、潇、沅 |
| 瑶 | 玉石美感但降热度 | 珂、琬、瑾、玥、璇、琮 |

### 3. 候选集合去同质化规则

同一轮中文候选至少覆盖以下 3 项中的 3 项以上：

1. **不同语义轴**：如品德、自然、志向、光明、书卷、安宁
2. **不同构字路径**：如德性 + 山水、光明 + 智慧、草木 + 雅致
3. **不同声调走向**：如平仄平、仄平仄、平平仄
4. **不同字形结构**：左右、上下、半包围适度混合

不要生成这类“伪多样化”名单：

- 梓涵 / 梓萱 / 梓悦 / 梓宁 / 梓汐
- 浩轩 / 皓轩 / 皓宸 / 泽宸 / 宇宸

## 二、五行属性表

五行喜用是中文取名的重要依据。根据用户提供的五行喜用（金/木/水/火/土），优先选用对应五行属性的汉字；若用户同时要求低重名，先从“常用次高频字”里选，再考虑大众热字。

### 金属性字

偏旁部首含金、钅、刂、刀、辛、酉等，或字义与金属、锋利、坚硬、清正相关。

- 常用基础字：铭、钰、锐、锦、铮、铠、钦、铄、鉴、铎、铖、锴
- 低重名补充字：锟、锵、锶、锌、镕、镐、锏、钺、铂、钤、锆、镓

### 木属性字

偏旁部首含木、艹、竹、禾等，或字义与植物、生长、生机、文雅相关。

- 常用基础字：桐、栩、楠、楷、柏、枫、荣、芸、芷、萱、蕊、菲
- 低重名补充字：榆、棠、槿、柠、筠、苒、葭、茉、芮、蘅、莘、蔚

### 水属性字

偏旁部首含氵、冫、雨、鱼等，或字义与水、流动、滋润、澄明相关。

- 常用基础字：泽、润、渊、澈、澜、溪、霖、淳、沛、沁、漪
- 低重名补充字：沅、泠、洵、渝、潞、濯、澹、澧、淞、湉、沄、涔

### 火属性字

偏旁部首含火、灬、日、光等，或字义与光明、温暖、热烈、希望相关。

- 常用基础字：煜、炜、烨、灿、耀、晖、旭、晨、曦、熠、煦、焕
- 低重名补充字：昀、晟、旸、昭、曜、晗、炯、焜、炘、暄、晞、炫

### 土属性字

偏旁部首含土、山、石、玉等，或字义与大地、稳重、厚重、守成相关。

- 常用基础字：坤、城、培、垣、硕、瑛、瑞、瑾、瑜、珂、璟
- 低重名补充字：砚、岑、峤、岳、衡、堃、琮、琛、璨、珩、嵘、嶷

## 三、风格矩阵

### 1. 书卷气

- 关键词：清朗、文雅、思辨、修养
- 常用字：言、知、书、墨、闻、思、允、谦、砚、修、简、惟
- 推荐组合：书 + 山水、思 + 光明、知 + 品德

### 2. 大气格局

- 关键词：开阔、担当、远志、稳健
- 常用字：岳、衡、峻、川、鸿、远、承、拓、维、旷、瀚、廷
- 推荐组合：山岳 + 志向、秩序 + 格局、天空 + 行动

### 3. 温润雅正

- 关键词：和善、端方、克制、内秀
- 常用字：和、宁、恺、谦、温、恬、安、澄、穆、祺、雍、忻
- 推荐组合：德性 + 安宁、水意 + 品德

### 4. 灵动清新

- 关键词：轻盈、敏锐、明快、自然
- 常用字：沅、泠、漪、昕、岚、棠、芮、苒、知、灵、晗、沐
- 推荐组合：水意 + 晨光、草木 + 灵气、云气 + 音律

### 5. 古典含蓄

- 关键词：诗意、余韵、典雅、留白
- 常用字：蘅、葭、霁、绥、叙、弦、绮、筠、郁、徵、令、棣
- 推荐组合：草木 + 乐音、天象 + 文雅、礼序 + 柔美

### 6. 现代简洁

- 关键词：利落、干净、不过度修饰
- 常用字：予、可、行、亦、维、宁、安、禾、元、川、景、序
- 推荐组合：单义强字 + 安定字、行动字 + 光明字

## 四、语义组合模板

以下模板可显著降低“热门字堆砌”问题。优先跨模板生成，而不是只在一个模板里替换单字。

1. **品德 + 志向**：谦远、允承、恺岳、修衡
2. **光明 + 智慧**：昭睿、晗哲、昀知、曜思
3. **山水 + 品性**：澄谦、沐和、峻诚、岳宁
4. **草木 + 雅致**：筠雅、棠宁、槿书、芮清
5. **节气 + 气质**：霁安、清晏、知夏、景和
6. **乐音 + 文采**：闻弦、清徵、知音、叙和
7. **秩序 + 格局**：维则、承序、景衡、允度
8. **自然 + 灵动**：沅昕、岚汐、芮澄、漪宁

如用户要求“双名”，优先让两个字分别承担不同语义角色，不要双字都堆在同一方向。

## 五、音韵平仄规则

### 声调基础

现代汉语四声：
- 第一声（阴平）与第二声（阳平）为平声
- 第三声（上声）与第四声（去声）为仄声

### 平仄搭配原则

1. **避免三字同声调**
2. **优先平仄交替**
3. **根据气质选择结尾**
   - 平声收尾：柔和、舒展
   - 仄声收尾：利落、有力

### 推荐声调组合（三字名）

| 组合 | 气质 | 提示 |
|---|---|---|
| 平仄平 | 温润、耐听 | 适合书卷气、文雅风 |
| 仄平仄 | 铿锵、清晰 | 适合大气、担当风 |
| 平平仄 | 先铺陈后收束 | 适合温和但不弱 |
| 仄平平 | 先立后扬 | 适合简洁现代风 |

### 拗口读音规避

1. 避免声母完全重复，如「李丽琳」
2. 避免韵母过度同质，如「金瑾琴」
3. 避免鼻音堆积，如「陈晨辰」
4. 开口音与闭口音适度搭配，增强节奏层次

## 六、辈分适配指南

### 辈分字处理原则

1. 辈分字可在中间或末尾，先遵守家族规则
2. 若辈分字过于常见，搭配字要主动拉开风格
3. 若辈分字偏硬，搭配字可用柔和或雅字平衡
4. 若辈分字偏柔，搭配字可用格局或志向字提气

### 常见辈分字搭配思路

- 德：德行、品格、温厚 → 德谦、德昭、德衡、德沅
- 志：志向、抱负、担当 → 志澄、志岳、志闻、志晗
- 文：文采、书卷、修养 → 文筠、文昀、文澈、文棠
- 家：家风、承续、稳重 → 家承、家宁、家序、家谦

## 七、避讳字与风险清单

### 绝对禁用类

1. 生僻字：避免显著超出常用教育与证件场景范围的字
2. 异体字：如「峯」「昇」
3. 贬义字：丧、亡、疾、苦、哀、残、劣等
4. 明显不雅谐音：
   - 杜子腾 → 肚子疼
   - 史珍香 → 屎真香
   - 焦厚根 → 脚后跟
   - 魏生津 → 卫生巾
   - 沈京兵 → 神经病

### 默认降权类

- 过度网红化的字：梓、宸、诺、汐、萌、熙（除非用户明确喜欢）
- 语义过满的“大词”：帝、皇、圣、尊、霸
- 容易显得用力过猛的字：傲、狂、绝、战、巅

### 谐音核查方法

1. 正向连读
2. 倒读
3. 主要方言谐音
4. 姓名首字母缩写

## 九、取名自检清单

生成中文名后，逐项核查：

- [ ] 字形美观：结构匀称，笔画适中（单字建议 5-20 画）
- [ ] 声调搭配：无三字同声调，节奏自然
- [ ] 无拗口读音：声母不重复，韵母不过密
- [ ] 五行符合：若有五行要求，字属性匹配
- [ ] 辈分融入：若有辈分字，衔接自然
- [ ] 无生僻异体字：尽量控制在日常教育/证件友好范围
- [ ] 无贬义不雅谐音：正向、反向、方言、缩写均检查
- [ ] 寓意积极：整体意境明确正向
- [ ] 低重名：不过度依赖高频热字与爆款模板
- [ ] 集合多样性：同轮候选之间不是“换一个字”的伪差异
